# Privacy Policy 

This project is designed to serve a small number of people who are interested in viewing a live example of my work. There are no tracking cookies set in the user's browser. This site is hosted by Cloudflare, but analytics are turned off, allowing even greather privacy to the user.

User authentication and management is provided through Clerk, which collects the following information:
* browser name and version
* IP address and estimated location
* date and time of last login

Comments are disabled, so there is no user-submitted data on this site.

# Terms of Use

This project is for showcasing on my portfolio. The username and password are to be shared only people who would like to see a live example of my work. Visitors cannot make accounts nor edit the user account they use. Please do not share the username and password without my express permission. Usernames and passwords are subject to changed on my whim, with no prior warning to users. Clerk also allows for devices to be revoked.

Additionally, comments are disabled on this project. There are no writes to the database.
